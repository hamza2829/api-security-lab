# api-security-lab

A local learning lab: attack a small FastAPI app, prove four deliberate bugs,
fix them, and run the same attacks as regression tests. Python and SQLite only.
All records and credentials are synthetic. Bind the app to 127.0.0.1 only.

The vulnerable app and exploits arrive in the first pull request. The fixed app,
regression tests, and complete report arrive in the second pull request.
